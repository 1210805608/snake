# Snake Game

A lightweight browser-based Snake game built with vanilla HTML, CSS, and JavaScript.

## Features
- Keyboard controls: Arrow keys and WASD
- Pause and resume with Space
- Persistent high score via localStorage
- Responsive layout
- No external dependencies or build step

## Run locally
Open `index.html` in a modern browser. No installation is required.
